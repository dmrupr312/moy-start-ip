# «Мой старт ИП» — ИИ-агент для госуслуги «Регистрация ИП»

Агент помогает человеку пройти регистрацию индивидуального предпринимателя с первого раза и сразу выбрать налоговый режим, который ему выгоден:

1. **Подбирает коды ОКВЭД** по описанию деятельности своими словами.
2. **Сравнивает 7 налоговых режимов в рублях**: НПД, УСН 6%, УСН 15%, ПСН, АУСН 8%/20%, ОСНО. Учитывает правила 2026–2027 годов: взносы, НДС на УСН свыше 20 млн, лимит ПСН 20/15 млн, прогрессивный НДФЛ.
3. **Составляет пошаговый план**: канал подачи, документы, сроки уведомлений (УСН — 30 дней).
4. **Проверяет данные для заявления Р21001** на типовые основания отказа (ст. 23 129-ФЗ) и собирает черновик по листам формы.

Агент работает с любой LLM (GigaChat, YandexGPT, OpenRouter, Ollama…). **Без ключа он тоже работает** — в офлайн-режиме «мастера» на тех же инструментах, поэтому демо не сломается из-за сети или лимитов.

Зависимостей нет: только Python 3.10+ из коробки.

---

## Быстрый старт (2 минуты)

```bash
cd ip-agent
python3 app.py
# откройте http://localhost:8000
```

На Windows: `py app.py`.

Проверка: `python3 -m unittest discover -s tests -v` — 18 тестов.

## Подключение LLM

Скопируйте `.env.example` в `.env` и заполните **один** вариант. После этого перезапустите `app.py`. Режим работы показан в правом верхнем углу страницы.

### GigaChat (рекомендуется: российская модель, есть бесплатный лимит для физлиц)
1. Зайдите на developers.sber.ru → Studio → создайте проект **GigaChat API** (тариф Freemium для физлиц).
2. В настройках проекта скопируйте **Ключ авторизации** (Authorization key).
3. В `.env`:
   ```
   LLM_PROVIDER=gigachat
   GIGACHAT_AUTH_KEY=<ключ>
   ```
4. GigaChat использует сертификат НУЦ Минцифры. Скачайте корневой сертификат «Russian Trusted Root CA» (на Госуслугах, раздел «Сертификаты Минцифры»), положите рядом и укажите `GIGACHAT_CA_BUNDLE=./russian_trusted_root_ca.cer`. Для быстрого демо можно временно поставить `GIGACHAT_VERIFY_SSL=false`, но в продакшене так делать нельзя.

### YandexGPT
```
LLM_PROVIDER=yandex
YANDEX_API_KEY=<API-ключ сервисного аккаунта с ролью ai.languageModels.user>
YANDEX_FOLDER_ID=<ID каталога>
```

### OpenRouter / любой OpenAI-совместимый API
```
OPENROUTER_API_KEY=sk-or-...
LLM_MODEL=<любая модель; бесплатные помечены ":free" на openrouter.ai/models>
```
Локально через Ollama: `LLM_BASE_URL=http://localhost:11434/v1`, `LLM_MODEL=qwen2.5:7b`.

## Деплой

### Вариант A. Docker (любой сервер или облако)
```bash
docker build -t moy-start-ip .
docker run -d -p 8000:8000 --env-file .env --restart unless-stopped --name ip-agent moy-start-ip
```

### Вариант B. VPS (Timeweb Cloud, Selectel, Yandex Compute Cloud, ~200–300 ₽/мес)
```bash
sudo apt update && sudo apt install -y python3 git
git clone <ваш-репозиторий> /opt/ip-agent        # или scp архива
cd /opt/ip-agent && cp .env.example .env && nano .env
sudo tee /etc/systemd/system/ip-agent.service <<'EOF'
[Unit]
Description=Moy Start IP agent
After=network.target
[Service]
WorkingDirectory=/opt/ip-agent
ExecStart=/usr/bin/python3 /opt/ip-agent/app.py
Restart=always
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now ip-agent
```
Для HTTPS поставьте перед приложением nginx с сертификатом Let's Encrypt (`certbot --nginx`).

### Вариант C. Yandex Cloud Serverless Containers
Соберите образ из `Dockerfile`, загрузите его в Container Registry, создайте Serverless Container с переменными из `.env` и портом 8000, включите публичный доступ.

### Вариант D. Быстрая публичная ссылка для защиты (с ноутбука)
```bash
python3 app.py &
cloudflared tunnel --url http://localhost:8000     # или: ngrok http 8000
```
Ссылку можно дать жюри, чтобы они проверили агента со своих телефонов.

### Telegram-бот (необязательно)
Получите токен у @BotFather, добавьте `TELEGRAM_BOT_TOKEN` в `.env` и запустите `python3 telegram_bot.py`.

## Архитектура

```
Пользователь (веб-чат / Telegram)
        │
        ▼
app.py ─ HTTP API (/api/chat, /api/calc, /api/okved, /api/precheck)
        │
        ▼
agent/core.py ─ оркестратор: сессии, извлечение профиля, цикл «LLM → инструмент → LLM»
        │                         (если LLM недоступна → офлайн-мастер)
        ├── agent/okved.py      подбор ОКВЭД (справочник ~65 частых кодов)
        ├── agent/rules.py      калькулятор режимов, параметры 2026–2027, источники
        ├── agent/checklist.py  план регистрации, предпроверка Р21001, черновик
        └── agent/llm.py        клиенты GigaChat / YandexGPT / OpenAI-совместимых API
```

**Как устроено**: LLM отвечает только за диалог и решает, какой инструмент вызвать. Числа, ставки, лимиты и сроки считает детерминированный код. Поэтому агент не «галлюцинирует» налоги. Протокол вызова инструментов — JSON в ответе модели, он работает даже с моделями без function calling.

**Персональные данные**: сессии хранятся только в памяти (1 час), в логи не пишутся, паспортные данные нужны лишь для необязательной предпроверки.

## Сценарий демо (3 минуты)
1. Кнопка «💅 Маникюр» → агент подбирает 96.02, выбирает НПД и показывает разницу с самым дорогим режимом.
2. Напишите «а если доход 4 млн в год и 1 сотрудник с зарплатой 50 тысяч в месяц» → НПД отключается, агент пересчитывает режимы.
3. Кнопка «📦 Маркетплейс» → появляется НДС на УСН (доход больше 20 млн), патент недоступен из-за лимита 2027 года.
4. Вкладка «Проверка заявления»: введите ОКВЭД «96» и паспорт из 9 цифр → риск отказа «высокий», агент объясняет, что исправить.

## Ограничения
- Это оценка за полный год для сравнения режимов, а не налоговая консультация. Стоимость патента зависит от региона: её нужно взять в калькуляторе ФНС.
- Справочник ОКВЭД — выборка частых кодов. В промышленной версии он заменяется на полный ОК 029-2014 с поиском по эмбеддингам.
- Взносы за работников посчитаны упрощённо (30%).
