# «Мой старт ИП» — ИИ-агент для госуслуги «Регистрация ИП»

Агент помогает пройти регистрацию индивидуального предпринимателя с первого раза и сразу выбрать выгодный налоговый режим:

1. **Подбирает коды ОКВЭД** по описанию деятельности своими словами.
2. **Сравнивает 7 налоговых режимов в рублях** (НПД, УСН 6% и 15%, ПСН, АУСН 8% и 20%, ОСНО) по правилам 2026–2027 годов.
3. **Даёт аналитику**: эффективная ставка, доход «на руки», кривые нагрузки при росте дохода и точки перелома, близость к лимитам, календарь платежей.
4. **Составляет план регистрации** и **проверяет данные заявления Р21001** на типовые основания для отказа.
5. **Показывает аналитику самой услуги**: статистика, реформа 2026, типичные заявители, модель эффекта.

Работает с любой LLM (GigaChat, YandexGPT, OpenRouter, Ollama). Без ключа — офлайн-режим «мастера» на тех же инструментах.
Внешних зависимостей нет: только Python 3.10+.

---

## Публичный хостинг — Render (бесплатно, без карты)

1. **GitHub.** Зарегистрируйтесь на github.com → «New repository» → имя `moy-start-ip`, Public → Create.
   На странице репозитория нажмите «uploading an existing file» и перетащите **содержимое** папки `ip-agent`
   (файлы `app.py`, `render.yaml`, папки `agent`, `static`, `tests` и т.д.) → «Commit changes».
2. **Render.** Зарегистрируйтесь на render.com через GitHub → «New +» → **Blueprint** → выберите репозиторий `moy-start-ip`.
3. Render прочитает `render.yaml` и спросит переменные. Для GigaChat:
   `LLM_PROVIDER = gigachat`, `GIGACHAT_AUTH_KEY = ваш ключ`. Остальные оставьте пустыми.
   Без ключа — оставьте всё пустым, агент будет в офлайн-режиме.
4. Нажмите **Apply**. Через 2–3 минуты появится адрес вида `https://moy-start-ip.onrender.com`.

Особенность бесплатного тарифа: после 15 минут без посещений сервис засыпает, первый заход будит его около минуты.
Откройте ссылку за 2–3 минуты до защиты. Чтобы не засыпал совсем — пингуйте `/api/health` каждые 10 минут
(например, cron-job.org): 750 бесплатных часов в месяц хватает на один сервис круглосуточно.

Если GigaChat не подключается с серверов Render (они за рубежом) — агент сам переключится в офлайн-режим;
для LLM-режима используйте Amvera ниже или ключ OpenRouter (`OPENROUTER_API_KEY`, `LLM_MODEL`).

## Публичный хостинг — Amvera Cloud (российское облако)

Подходит, если нужен GigaChat с российских серверов и нет «засыпания». При регистрации начисляется стартовый баланс.
1. cloud.amvera.ru → регистрация → «Создать проект» → тип «Приложение».
2. Загрузите файлы проекта через интерфейс (или `git push`) — в архиве уже есть `amvera.yaml` и `Dockerfile`.
3. В разделе «Переменные» добавьте `LLM_PROVIDER=gigachat`, `GIGACHAT_AUTH_KEY=...`, `GIGACHAT_VERIFY_SSL=false`.
4. Во вкладке «Домены» включите бесплатный домен — получите публичную ссылку.

## Запуск локально

```bash
python3 app.py          # Windows: py app.py
# http://localhost:8000
```
Ключ LLM — в файле `.env` (образец в `.env.example`). Тесты: `python3 -m unittest discover -s tests -v`.

## Как получить ключ GigaChat
developers.sber.ru/studio → вход по Сбер ID → проект **GigaChat API** (тариф Freemium для физлиц) →
«Сгенерировать ключ» → скопируйте **Ключ авторизации**. Для продакшена вместо `GIGACHAT_VERIFY_SSL=false`
укажите сертификат НУЦ Минцифры в `GIGACHAT_CA_BUNDLE`.

## Другие варианты деплоя
- **Docker:** `docker build -t moy-start-ip . && docker run -p 8000:8000 --env-file .env moy-start-ip`
- **VPS** (Timeweb, Selectel, Yandex Cloud): `python3 app.py` как systemd-сервис + nginx с HTTPS.
- **Временная ссылка с ноутбука:** `cloudflared tunnel --url http://localhost:8000`.
- **Telegram-бот:** `TELEGRAM_BOT_TOKEN=... python3 telegram_bot.py`.

## Архитектура

```
Веб-чат / Telegram ─► app.py (HTTP API, ограничение частоты запросов)
                         └► agent/core.py — оркестратор: сессии, извлечение профиля, цикл «LLM → инструмент»
                               ├ agent/okved.py      подбор ОКВЭД
                               ├ agent/rules.py      калькулятор режимов, параметры 2026–2027
                               ├ agent/analytics.py  кривые нагрузки, точки перелома, календарь, лимиты, аналитика услуги
                               ├ agent/checklist.py  план регистрации, предпроверка Р21001
                               └ agent/llm.py        GigaChat / YandexGPT / OpenAI-совместимые API
```
LLM ведёт диалог и выбирает инструмент; все суммы, ставки и лимиты считает детерминированный код (21 автотест).

API: `POST /api/chat`, `/api/analyze`, `/api/calc`, `/api/okved`, `/api/precheck`, `/api/service`; `GET /api/health`.
На публичном сайте действует лимит: 20 сообщений в чат и 120 запросов к API в минуту с одного IP
(`CHAT_LIMIT_PER_MIN`, `API_LIMIT_PER_MIN`).

## Ограничения
Оценка за полный год для сравнения режимов, не налоговая консультация. Стоимость патента зависит от региона.
Справочник ОКВЭД — выборка частых кодов. Взносы за работников посчитаны упрощённо (30%).
